flootlets uses [shadcn/ui's theme variables](https://ui.shadcn.com/docs/theming), plus
`--success` and `--warning` in the same pattern. Each colour has a `-foreground` for text on
top of it.

The values are shadcn/ui's **neutral** theme, a placeholder until a shop brings its own. A few are
adjusted just enough to meet WCAG AA, which shadcn's defaults miss:

- `--input` has more contrast in both themes, so input borders reach 3:1 against the page
  (shadcn's is 1.3:1 in light, 1.5:1 in dark);
- `--ring` is darker in light mode, so the focus ring reaches 3:1;
- `--muted-foreground` and `--destructive` are a touch darker in light mode, so they stay at
  4.5:1 as text on `--muted`.

This page reads `theme.css` directly, so it always shows the current values.

## Radius

`--radius` is <code>{radius}</code>. As in shadcn, Tailwind's radii are derived from it:
`rounded-lg` is `--radius`, `rounded-md` and `rounded-sm` are 2px and 4px smaller, and
`rounded-xl` is 4px larger.

## Everything else

Spacing, type, shadows and motion use Tailwind's own scales.
