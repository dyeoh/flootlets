The palette is ink black, a brush red and paper white. Red is used as a **fill** in both themes
(white on brush red is 8.35:1). Red **text** on the dark background uses a lighter red, because
brush red on ink is only 2.4:1, far below the 4.5:1 that text needs.

This page reads `tokens.css` directly, so it always shows the current values.

## Other scales

| Group    | Tokens                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| Spacing  | `--fl-space-0` … `--fl-space-16` (0.25rem steps: `--fl-space-4` is 1rem)                                   |
| Radius   | `--fl-radius-sm` (5px), `-md` (10px), `-lg` (20px), `-pill`                                                |
| Type     | `--fl-text-xs` … `--fl-text-5xl`, `--fl-font-body`, `--fl-font-heading`, `--fl-weight-*`, `--fl-leading-*` |
| Controls | `--fl-control-sm` (2rem), `-md` (2.75rem, a comfortable touch target), `-lg`                               |
| Motion   | `--fl-duration-fast` / `-normal` / `-slow` (all 0 with reduced motion), `--fl-ease`                        |
| Shadows  | `--fl-shadow-sm` / `-md` / `-lg` (stronger in dark mode)                                                   |
| Layers   | `--fl-z-dropdown`, `--fl-z-overlay`, `--fl-z-toast`                                                        |
