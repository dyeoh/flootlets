flootlets' colours and radius are [shadcn/ui theme variables](https://ui.shadcn.com/docs/theming)
(`--primary`, `--muted-foreground`, `--radius`…), plus `--success` and `--warning`. Change a
handful of them and everything follows. See [Theme variables](/flootlets/tokens/) for the full
list.

## With Tailwind

Import the theme after Tailwind. It maps every variable into Tailwind, so `bg-primary` or
`text-muted-foreground` in your own markup follow the theme too:

```css
@import 'tailwindcss';
@import 'flootlets/theme.css';
```

## Override variables

Put overrides in your own CSS. Order doesn't matter: flootlets' variables live in Tailwind's
`base` layer, and styles outside a layer always win.

```css
:root {
  --primary: #0064ff; /* buttons, links, sale prices, focus */
  --primary-foreground: #ffffff;
  --ring: #0064ff;
  --radius: 0.375rem; /* squarer corners */
}
.dark {
  --primary: #6fa8ff;
  --primary-foreground: #050706;
}
```

`--primary` is used both as a fill (with `--primary-foreground` on it) and as text on the page,
so it needs at least **4.5:1** contrast against both. The same goes for `--destructive`,
`--success` and `--warning`. Focus rings (`--ring`) and input borders (`--input`) need 3:1.

## Use a shadcn or tweakcn theme

Any theme from [shadcn/ui](https://ui.shadcn.com/themes) or [tweakcn](https://tweakcn.com/)
works: paste its `:root` and `.dark` blocks into your CSS. If it has no `--success` and
`--warning`, add them. Then check it, from a clone of the flootlets repo:

```sh
bun run check:theme path/to/my-theme.css
```

It reads hex, `rgb()`, `hsl()`, `oklch()` and shadcn v3's bare `H S% L%` values, composites
translucent colours over the background, and reports every pair below WCAG AA in light and dark.

## Light and dark

By default flootlets follows the visitor's system setting (`prefers-color-scheme`). To force a
theme, put `class="dark"` or `class="light"` (shadcn's and next-themes' convention), or
`data-theme="dark"` / `data-theme="light"`, on `<html>` or on any element to theme just that part
of the page:

```html
<html class="dark">
  …
  <section class="light">A light panel on a dark page.</section>
</html>
```

This site's theme picker sets `data-theme` on `<html>`, and the examples follow.

Tailwind's `dark:` variant follows the same rules: `.dark`, `data-theme="dark"`, or the system
setting when neither theme is forced.

A pasted shadcn theme only switches with the `.dark` class. To keep following the system setting,
repeat its dark block for it:

```css
@media (prefers-color-scheme: dark) {
  :root:not(.light, [data-theme='light']) {
    /* the same variables as .dark */
  }
}
```

## Restyle one component

Components have stable class names (`fl-button`, `fl-price__was`) and expose their state as data
attributes (`data-variant`, `data-size`, `data-loading`). Target those, or set the component's
own variables:

```css
.fl-button[data-variant='primary'] {
  --fl-button-bg: var(--foreground);
  text-transform: uppercase;
}
```
