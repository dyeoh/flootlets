---
title: Theming
description: Restyle flootlets by overriding CSS variables, and control light and dark.
---

Every colour, size, radius and duration in flootlets is a CSS custom property. Components only
use the **semantic** tokens (like `--fl-color-accent`), so changing a handful of variables
restyles everything.

## Override tokens

Put overrides in your own CSS. It doesn't need to be more specific: flootlets' rules live in
cascade layers, and styles outside a layer always win.

```css
:root {
  --fl-color-accent: #0064ff; /* fills: primary buttons, accent badges */
  --fl-color-accent-hover: #0050cc;
  --fl-color-accent-text: #0050cc; /* links, sale prices */
  --fl-color-focus: #0064ff;
  --fl-radius-pill: 6px; /* squarer buttons */
  --fl-font-body: 'Inter', system-ui, sans-serif;
}
```

Keep text tokens readable: at least **4.5:1** contrast with the backgrounds they sit on
(3:1 for focus rings and input borders). flootlets' own tokens are tested for this in both
themes; see [Design tokens](/flootlets/tokens/).

## Light and dark

By default flootlets follows the visitor's system setting (`prefers-color-scheme`). To force a
theme, set `data-theme` on `<html>`, or on any element to theme just that part of the page:

```html
<html data-theme="dark">
  …
  <section data-theme="light">A light panel on a dark page.</section>
</html>
```

This site's theme picker does exactly that: it sets `data-theme` on `<html>`, and the examples
follow.

To change a colour for dark mode only, override it inside the dark selectors:

```css
[data-theme='dark'] {
  --fl-color-accent-text: #ff7a8a;
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme='light']) {
    --fl-color-accent-text: #ff7a8a;
  }
}
```

## Restyle one component

Components have stable class names (`fl-button`, `fl-price__was`) and expose their state as data
attributes (`data-variant`, `data-size`, `data-loading`). Target those, or set the component's
own variables:

```css
.fl-button[data-variant='primary'] {
  --fl-button-bg: var(--fl-color-text);
  text-transform: uppercase;
}
```
