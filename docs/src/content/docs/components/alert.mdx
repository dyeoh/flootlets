Use an Alert for messages tied to the page or a form that the shopper may need to act on. A
`destructive` alert is a `role="alert"`, announced straight away; the other variants are
`role="status"`, announced when the screen reader is free. With `onDismiss` it gets a labelled
close button.

The gnerkulfloot API's checkout errors carry a `code` (`out_of_stock`, `shipping_unavailable`…).
Map those to friendly text in an Alert near the place it applies.

| Prop           | Type                                                   | Default                  |
| -------------- | ------------------------------------------------------ | ------------------------ |
| `variant`      | `'default' \| 'destructive' \| 'success' \| 'warning'` | `'default'`              |
| `title`        | JSX                                                    |                          |
| `onDismiss`    | `() => void`                                           | Shows the dismiss button |
| `dismissLabel` | `string`                                               | `'Dismiss'`              |

Classes: `alertVariants({ variant })`. Parts: `data-slot="alert"`, `alert-title`,
`alert-description`.
