Built on Kobalte's Dialog. When it opens, focus moves inside and **stays** inside (Tab cycles
through its controls). Escape, the × button or clicking outside closes it, and focus goes back to
whatever opened it. The page behind doesn't scroll. The `title` names the dialog for screen
readers, and `description` is read with it.

Give it a `trigger` (props for the [Button](/flootlets/components/button/) that opens it), or leave
the trigger out and control it with `open` / `onOpenChange` from your own button.

| Prop                                    | Type                        |                                       |
| --------------------------------------- | --------------------------- | ------------------------------------- |
| `title`                                 | `string`                    | Required. Heading and accessible name |
| `description`                           | JSX                         |                                       |
| `children`                              | JSX                         | The body                              |
| `footer`                                | JSX                         | Actions, right-aligned                |
| `trigger`                               | Button props                | A button that opens it                |
| `open` / `defaultOpen` / `onOpenChange` |                             | Control it yourself                   |
| `size`                                  | `'sm' \| 'default' \| 'lg'` | Width; default `default` (32rem)      |
| `closeLabel`                            | `string`                    | Default "Close"                       |
