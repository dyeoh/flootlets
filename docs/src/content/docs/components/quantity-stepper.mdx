Built on Kobalte's NumberField. The number is a **spinbutton**: arrow keys step it, Page Up/Down
step further, Home/End jump to the limits, and you can type a number. The − and + buttons switch
off at `min` and `max`. When − or + is pressed, the new quantity is announced to screen readers
(focus is on the button then, so the field's own announcement wouldn't be heard).

`min` defaults to **1**: taking an item out of the cart should be a separate, clearly labelled
"Remove" button, not a quantity of 0. Set `max` to the stock left; the gnerkulfloot API still
checks stock when the order is placed.

The field is only as wide as its content (the stepper, or a longer label or description), so it
lines up with the stepper instead of stretching across a column. Pass `class="w-full"` to stretch it.

## Disabled

With `disabled`, e.g. when the item is sold out, the whole stepper dims, the number with it, and
shows the not-allowed cursor, and nothing steps.

## Props

| Prop                                                   | Type                                            |                                                                                  |
| ------------------------------------------------------ | ----------------------------------------------- | -------------------------------------------------------------------------------- |
| `label`                                                | `string`                                        | Required, e.g. "Quantity". Use `hideLabel` in a compact cart row                 |
| `value` / `defaultValue` / `onChange`                  | `number` / `number` / `(value: number) => void` | `onChange` runs only when the value really changes, never on first render        |
| `min`, `max`, `step`                                   | `number`                                        | Defaults 1, none, 1                                                              |
| `size`                                                 | `'sm' \| 'default'`                             |                                                                                  |
| `labels`                                               | `{ decrement?: string; increment?: string }`    | Button labels for translation. Default "Decrease quantity" / "Increase quantity" |
| `description`, `error`, `name`, `required`, `disabled` |                                                 |                                                                                  |
