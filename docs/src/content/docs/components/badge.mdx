The text always carries the meaning ("Sold out"); colour only reinforces it, so the badge still
works for colour-blind visitors and in monochrome.

| Prop      | Type                                                                               | Default     |
| --------- | ---------------------------------------------------------------------------------- | ----------- |
| `variant` | `'default' \| 'secondary' \| 'destructive' \| 'outline' \| 'success' \| 'warning'` | `'default'` |

The first four are shadcn/ui's Badge variants; `success` and `warning` follow the same pattern.
Classes: `badgeVariants({ variant })`, so a link can look like a badge. State: `data-variant`.
